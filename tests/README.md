# Контрольні

Кожна контрольна — окремий файл `tests/<клас>-<чверть>.js`, наприклад `5-1.js` (5 клас, I чверть).
Файл викликає `registerTest({...})` з полями:

- `id` — код контрольної, такий самий, як ім'я файлу (`'6-2'`);
- `grade`, `quarter` — клас і чверть;
- `title`, `label`, `about`, `intro` — назва, підпис («6 клас, II чверть»), опис і привітання Біта;
- `levels()` — функція, що повертає список рівнів (див. `5-1.js`).

Щоб додати контрольну:
1. Створити файл у `tests/` і картинки (наприклад, у `media/6-2/`).
2. Додати рядок `<script src="tests/6-2.js"></script>` в `index.html` поруч з іншими.
3. На панелі вчителя → «Розбір і налаштування» → «Активні контрольні» обрати її для потрібної паралелі.
